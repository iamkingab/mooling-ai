## 🚀 快速开始

### 环境要求

```bash
Node.js >= 16.0.0
npm >= 8.0.0 或 pnpm >= 7.0.0 (推荐)
```

### 安装与运行

```bash
# 克隆仓库
git clone https://github.com/iamkingab/mooling-ai.git
cd mooling-ai

# 安装依赖
pnpm install

# 启动开发服务器
pnpm dev

# 构建生产版本
pnpm build
```

### 首次使用

1. **配置 AI 服务**: 点击右上角「API 配置」，添加您的 API 密钥
2. **创建项目**: 选择小说类型，输入基本信息
3. **开始创作**: 使用 AI 辅助工具开始您的创作之旅

## 📖 功能介绍

### 🎯 **智能创作引擎**
- **智能续写**: 自定义续写方向和字数要求(200-5000字)
- **AI 内容润色**: 语法、文风、情感、逻辑多维度润色
- **实时流式输出**: 可随时停止，完整内容预览

### 📚 **小说管理**
- **项目创建**: 多类型小说模板，一键生成项目结构
- **章节编辑**: 专业写作编辑器，支持 Markdown 和富文本
- **版本控制**: 自动保存，防止内容丢失

### 💬 **智能提示词库**
- **分类管理**: 大纲生成、正文创作、润色优化、对话场景等
- **专业模板**: 基础正文、对话生成、场景描写、动作情节等
- **变量系统**: 支持动态变量替换

### 🌟 **世界观构建**
- **复杂设定支持**: 科幻修仙、赛博朋克等复杂世界观
- **模板化管理**: 核心设定、关键元素、故事背景
- **一致性检查**: AI 驱动的世界观一致性验证
